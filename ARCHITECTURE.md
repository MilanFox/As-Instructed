# ARCHITECTURE

Player TS → Monaco transpile → Web Worker (`Sim` over a seeded `World`) → `Trace` → Canvas2D replay + audio cursor.
The renderer never talks to the sim; everything after the worker is a pure function of `initialWorld + events`. `runLevel` in `src/levels/harness.ts` is the reference the worker must reproduce byte-for-byte — where they disagree, the harness is right.

## Invariants the compiler and tests will not catch

- `Sim` must never consume `world.rng`. All randomness belongs to `LevelDef.build(seed)`; a verb that draws from it makes the trace unreplayable without re-running sim logic. Worlds 7-8 avoid `world.rng` at build time too, deriving `seed * 7919 + 13` (`src/levels/world-7/shared.ts:11`, `src/levels/world-8/shared.ts:30`). Same family, and trivial to delete by accident: `warm(rng)` burns exactly three draws (`src/levels/world-3/yard.ts:14`) because mulberry32 seeded 1, 2 and 3 returns near-identical first values — remove it and consecutive World 3 seeds yield the same crate count, with every test still green.
- Never mutate `sim.world` outside a verb that emits a matching event — level code goes through `applyTileChange` (`src/engine/sim.ts:822`), `applyMachineChange` (`:790`) or `refuseMachineAct` (`:782`). A refusal that throws must still push its event and charge *before* throwing. Either mistake diverges replay silently.
- Keyframes are cut by replaying the finished event list, never by snapshotting the live world (`src/engine/trace.ts:313`). With per-bot clocks the live world is not "the world at tick T". They must stay strippable.
- `FUEL_BURNING` (`src/engine/trace.ts:157`) must list exactly the event kinds `Sim.charge` is called for; it is read by both the live sim and `applyEvent`. A fuel-costing verb missing from it burns fuel live and not on replay.
- `enqueueMessage` inserts sorted by `(t, from)` rather than appending (`src/engine/world.ts:274`). A live run appends in issue order and a replay in `t` order; only the insert-sort makes the two inboxes agree once bot clocks skew. `recv` gates on `head.t <= bot.clock` (`src/engine/sim.ts:695`) for the same reason — hence the send → `sync` → `recv` idiom.
- `makespan` counts dead bots too (`src/engine/world.ts:341`). Filtering to living bots makes the replayed `world.tick` fall below the live one after any death.
- `blockReason` must be asked with the arrival clock (`t + cost`), not the issue clock. A bot holds a tile over `[arrival, departure)`, so a bot lagging on its own clock still cannot cross a tile another held at that time, even though the tile looks empty live.
- `setTile` preserves an existing occupant (`src/engine/world.ts:202`); `tile.occupant` is derived and `world.bots` is the truth. Hand-built or hand-edited worlds must call `rebuildOccupancy` (`:330`).
- Nothing ticks on its own. Crop maturity is derived from `plantedAt` against the observing bot's clock — build timed mechanics as derived state, never as scheduled updates.
- `postMessage` strips prototypes: a transferred `World` has `rng` as a bare `{state}`, so call `reviveWorld` (`src/engine/world.ts:399`) before touching one. `Infinity` does not survive the trip either.
- Treat a `Trace` as immutable. `replayTo` (`src/engine/trace.ts:411`) shares keyframe worlds; mutating one corrupts every later scrub. Read the requested tick from the caller — `world.tick` lags until a bot acts.
- A budget objective must declare its `meter`. Without one `src/game/budgets.ts` infers it by parsing the objective's English label, so rewording player-facing prose silently moves a budget off its meter.
- The terrain cache keys on `(cols, rows, biome, revision, cacheTilePx, art)` only (`src/render/terrain.ts:11`), and `revision` advances only on `tileChange` (`src/render/timeline.ts:334`). So nothing derived from the *tick* may be baked in — it goes stale, then double-draws under the live pass. Crops are the case to copy: `paintTerrain` bakes the furrows and never the plant (`src/render/art/deepsite.ts:919`). Nor may anything carrying a graded distinction go in, because cast shadows land on everything inside the cache and nothing painted after it.
- `poseAt(T)` must equal `replayTo(trace, T - 1)` (`src/render/__tests__/timeline.test.ts:90`). `replayTo` stamps an outcome at the tick the action *started*; the renderer animates it across `[t, t + dt)`. This off-by-one desyncs the entire board and is held by that test alone.
- The renderer's `seek` (`src/render/renderer.ts:407`) and the conductor's `seekTo` (`src/audio/conductor.ts:234`) duplicate one algorithm: re-find the cursor via `eventIndexAt`, then step past events landing exactly on `tick`. Let them drift and audio and FX disagree about which events have already fired. Any backwards or while-paused movement counts as a seek on both sides. Both sides seed variation from the trace event (`index * 2654435761 + round(event.t) * 97`, `src/audio/conductor.ts:273`), never `Math.random()`, so scrubbing back over a tick reproduces the same sound and particles.
- Level ids must keep sorting lexicographically in unlock order — `apiUnlockedBy` compares them as *strings* (`src/runtime/api-spec.ts:762`). A two-digit world or an unpadded index silently unlocks the wrong API set.
- The per-level API filter is a gameplay rule enforced as a type error: one unlocked-name list drives the ambient `.d.ts`, the runtime scope and the docs panel, so a locked call reads as `Cannot find name` in the editor. The `.d.ts` must stay a script — one top-level `import`/`export` makes every global declaration non-global.
- Every text rewrite in `src/runtime/modules.ts` must preserve its newline count, or every error line number below it shifts silently.
- One monaco model lives at `PLAYER_FILE_PATH` for the life of the app. `compilePlayerCode` emits through the typescript worker, which keeps its program keyed on that document's version (`src/runtime/compile.ts:153`), so disposing and recreating the model restarts the version at 1 and the next run executes the *previous* order's source — hence `keepCurrentModel` on the editor (`src/ui/workspace/MonacoBody.tsx:109`), and hence `RuntimeRunner.model` writing into the document rather than replacing it.
- Multi-seed results fold worst-seed **per objective**, not per run (`src/runtime/aggregate.ts:30`); the trace comes from the first failing seed, `libraryUsage` from the highest-tick seed (`:102`).
- The real adapters go into the store in `src/main.tsx`, before `createRoot().render()`. `mountRouter()` runs at import time, so an `/order/` URL leaves `screen` at `workspace` before React's first render and `FeedCanvas` hands its canvas to whatever `state.renderer()` returns then. `attachRenderer` cannot re-mount a canvas it never saw and `state.renderer` is a stable getter, so nothing re-runs on the swap — attach from an effect instead and the board is blank on a direct load only.
- `src/__tests__/unused-exports.test.ts` is a ratchet, not a lint. A barrel re-export does not count as a read (`:12`), `KNOWN_DEAD` is asserted by *set equality* (`:18`, `:190`) so deleting a dead export fails until you delete its allow-list line too, and `KNOWN_TEST_ONLY = [71, 32]` (`:72`) and `SCANNED_EXPORTS_AT_LEAST = 1500` (`:74`) only ever move one way.
- Three writes the compiler cannot see: `persist()` is the only legal write to `state.save` (`src/game/store.ts:241`) — a bare `set({ save })` typechecks and never reaches localStorage; `runToken` (`:402`) is the only thing stopping an abandoned run writing its verdict into the next work order; and `dependsOnLibrary` is caller-supplied and unverified (`src/meta/regression.ts:137`), so a level wrongly marked independent drops the library hash from its cache key and its re-runs pass forever against a stale library.
- UI tests run in `node` with a hand-cranked React driver whose `useEffect` is a no-op (`src/ui/__tests__/react-driver.ts:59`), so anything that must be testable belongs in a plain function the hook calls. Store selectors must also return a stable reference until their data changes (`src/ui/paper/papers.ts:309`) — a freshly filtered or sorted array re-renders forever.
- No read path in `src/game/save.ts` or `src/meta/` may discard source. An unrecognised id or shape is kept, not dropped — it belongs to a newer build. Retired achievement ids are never reissued. An *optional* new save field needs no `SAVE_VERSION` bump; a required one does. A `SAVE_VERSION` bump *without* a matching `MIGRATIONS` step (`src/game/save.ts:6`, `:81`) fails silently: `migrate` breaks out of the loop (`:146`) and falls through to the rescue pass.
- `src/__tests__/invariants.test.ts` holds six cross-module duplications that no import can express: an exported `SCREAMING_CASE` numeric constant declared in two files must have one value (`:29`); `SILVER_FACTOR` and `FUEL_BURNING` must each be declared in exactly one file (`:67`); the twelve palette colours must match between the canvas art and `tokens.css` (`:83`); `CelebrationKind` must be spelled identically in `src/game/ports.ts` and `src/render/renderer.ts` (`:100`); and each interface hand-copied into `api-spec.ts` as a template string must carry the fields the engine interface has (`:112`) — matched by two-space indentation, so reindenting an engine interface breaks the extraction.

## Constants whose value breaks something non-obviously

| file:line | constant | what breaks |
|---|---|---|
| `src/engine/verdict.ts:87` | `SILVER_FACTOR = 1.25` | Silver is `max(par + 1, par * 1.25)`. The `+1` floor is load-bearing: par under 4 otherwise has an empty silver band (`floor(3 * 1.25) === 3`). The copy shown to the player must state both halves; `invariants.test.ts:54` holds it. |
| `src/engine/sim.ts:41` | `DEFAULT_LIVELOCK_ROUNDS = 8` | Threshold is `rounds × livingBots`, not `rounds`, and never fires below 2 living bots — a lone bot bumping a wall is an ordinary bug. Lowering it aborts legitimate congested fleets as livelock. |
| `src/engine/world.ts:92` | pit `walkable: true, lethal: true` | Deliberate: the move *succeeds*, the bot arrives, then dies. Unwalkable turns pit into a wall and deletes the mechanic, which is why `TileView.lethal` was added on the reading side instead — a free field, so caution is not taxed. Void (`:82`) is `opaque` so `look()` cannot read past the site edge. |
| `src/runtime/protocol.ts:77` | `WORKER_TIMEOUT_MS = 5000` | The only defence against a loop that calls no API — engine tick/op budgets never fire because the engine is never entered. |
| `src/runtime/wrapper.ts:1` | `WRAPPER_PREAMBLE_LINES = 2` | Must equal the literal newline count in `wrapProgram`; a mismatch offsets every reported player line by a constant, silently. |
| `src/runtime/compile.ts:14,65` | `MODULE_DETECTION_FORCE = 3`; `strictNullChecks: false`, no DOM lib | The `3` is a hand-copied `ts.ModuleDetectionKind.Force` (Monaco does not re-export the enum); wrong, and a player program becomes a script sharing scope with the firmware declarations, giving redeclaration errors on names they never used. No DOM lib on purpose — otherwise `const name = ...` collides with `window.name`. Enabling strictness makes ordinary player JavaScript an error. |
| `src/audio/conductor.ts:8,14` | `BASE_TICKS_PER_SECOND = 4`, `MEDAL_BEAT = 0.14` | Duplicated in `src/game/store.ts:35` and `src/render/renderer.ts:85` rather than imported: `render` may not depend on `audio`, and the conductor needs a rate before the store supplies one. Guarded equal; unequal values separate sound from picture. |
| `src/render/art/deepsite.ts:142,156,1198` | `SOLID_RISE = 0.20`, `UMBRA = 0.32`, `SHADE = 0.34` | One lamp, north-west, never moves. `SHADE` and `UMBRA` sit within a hair of each other deliberately — two visibly different shadow densities read as two lamps, so do not merge them and do not spread them apart. Obstacle classes are separated by *height*, not hue, so the distinction survives greyscale. Shadow offset is `dx = dy = 1.4 × height`, never derived from elevation. |
| `src/levels/index.ts:95` | `levelIsGraded` true for unknown ids | Deliberate: a save written against a retired level keeps its medal rather than losing it to a lookup miss. Seven work orders were withdrawn, so `index` is ascending but not contiguous within a world. |
